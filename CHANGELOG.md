# Changelog

## 1.1

- Added compatibility improvements for Kerbalism Default, SIMPLEX Kerbalism, Kerbalism Science-Only, and Kerbalism RO.
- Improved ModuleManager patch staging so experiment settings, lab setup, and final rendered values apply in predictable phases.
- Ensured all experiment packages are available in stock-compatible installs through stock parts or fallback parts.
- Adjusted greenhouse experiment requirements to only require a greenhouse when the active Kerbalism profile provides one.
- Added support for profile-specific lab duration and resource scaling.
